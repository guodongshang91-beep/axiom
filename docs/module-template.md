# 新模块模板

`targets/_template/` 是占位模板，复制它，不要改它本体。目录结构固定：

```
targets/<name>/
├── README.md        # 必须：按下表填完
└── tools/           # 可选：能独立运行的脚本
    └── *.py
```

## README 必填四项

| 项 | 要回答什么 | 反例 |
| --- | --- | --- |
| 目标类型 | 这一层处理什么对象、不处理什么 | "各种逆向" |
| 首选工具 | 拿到对象后第一个跑什么，为什么是它 | 列十个工具不分主次 |
| 证据形态 | 结论靠什么材料支撑（见 evidence.md） | "看结果" |
| 复现方式 | 一条能跑的命令 + 预期输出 | "按步骤操作" |

另外写一段**已知局限**：工具不支持什么、什么情况下结论不成立。没有局限说明的模块不合并。

## 脚本要求

- `python <script> -h` 退出 0 且能自解释；`check.py` 会逐个跑。
- 单个脚本可独立运行，不依赖包内 import 路径。
- 路径、目标、端口走参数或环境变量，不写死本机绝对路径。
- 写操作提供 `--dry-run`，备份命名 `<file>.bak`。
- 输出原始材料，不输出"高危""疑似"这类判定词。
